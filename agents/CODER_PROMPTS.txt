SIDEQUEST CODER HANDOFF PROMPTS
==============================

RUN ORDER
---------

The shared app/API foundation already exists on main. Every coder must pull the same latest main commit before branching. All four prompts may then run concurrently.


PROMPT 1 — UI/UX AND APP FOUNDATION
------------------------------------

You own SideQuest's UI/UX and repository foundation.

Update main, then create branch: codex/ui-ux

Read these files completely before coding:
- agents/README.md
- agents/SHARED_CONTRACT.md
- agents/01_UI_UX_APP.md
- agents/INIT_PROMPTS.txt
- everything in design/

Then implement the task in agents/01_UI_UX_APP.md. Do not stop at planning. Build, test, and document the app foundation and deterministic demo mode.

Preserve unrelated work. Commit your changes, push the branch, and report:
1. commit SHA
2. tests/checks run
3. setup instructions
4. assumptions or remaining integration work

Do not merge the branch yourself.
